## 📌 Project Overview

This project simulates a real-world banking analytics engagement where transactional data is transformed into executive business intelligence.

The solution covers the complete analytics pipeline:

- Python ETL & Exploratory Data Analysis
- SQL Business Intelligence Queries
- Power BI Interactive Dashboards
- DAX Measures & Drill-through Analytics
- Executive KPI Reporting

**Dataset:** 100,000 Banking Transactions | 5,000 Customers

---

## 🎯 Business Objectives

- Analyze customer spending behavior
- Identify regional revenue trends
- Evaluate branch performance
- Compare payment channel adoption
- Build executive dashboards for decision making
- Enable customer-level drill-through reporting

# 📌 Key Insights

- Generated **₹398M** transaction revenue across 100K transactions.
- UPI emerged as the dominant digital payment channel.
- South region contributed the highest revenue.
- Customers aged **45+** generated the largest spending volume.
- Engineers and Analysts represented the strongest revenue-generating occupations.
- Interactive drill-through enables customer-level behavioral analysis.

### Python

